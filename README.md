## 1. Описание проекта

**Chess Game Recording System** — программная система для оцифровки шахматных партий в режиме реального времени по видеопотоку со стандартной физической доски (наборы Стаунтон) без использования электронных сенсоров (DGT) или модифицированных фигур.

Система построена на принципах **нейросимволического искусственного интеллекта (Neuro-Symbolic AI)**: вероятностные визуальные наблюдения согласуются со строгими символьными правилами FIDE и онтологией предметной области, исключая регистрацию невозможных ходов и накопление ошибок распознавания.

---

## 2. Ключевые возможности

* **Автоматическая локализация доски:** одношаговая детекция четырехугольника доски и перспективная гомография ($640 \times 640$).
* **Калибровка ориентации полей:** автоматическое определение ориентации $a1 \leftrightarrow h8$ по цвету угловых полей (правило FIDE) и начальной расстановке.
* **Компенсация параллакса 3D-высоты:** адаптивная вертикальная модификация области интереса клетки (Cell ROI) с фокусом на основание фигуры.
* **Изоляция помех рук и теней:** детекция кистей через MediaPipe Hand Landmarker и защитный интервал дебаунсинга ($\Delta t_{\text{settle}} \in [0{,}5; 1{,}0]$~с).
* **Пакетная нейросетевая классификация:** параллельный инференс содержимого 64 клеток через EfficientNet-B0 с возвратом распределений вероятностей.
* **Символьная валидация ходов:** фильтрация кандидатов по пространству легальных ходов $M(B_t)$ (`python-chess`) и топологическим сигнатурам (включая рокировку, взятие на проходе и превращение пешки).
* **Экспорт нотации:** генерация стандартных форматов FEN и PGN с сохранением доказательных кадров.
* **Асинхронный анализ:** фоновый расчет оценок позиции и грубых ошибок (blunders) шахматным движком Stockfish по протоколу UCI.

## 3. Архитектура системы

Система разделена на три слабосвязанных контура:

1. **Контур визуального восприятия (Vision):** адаптер кадров $\to$ детектор доски $\to$ блок гомографии $\to$ MediaPipe $\to$ классификатор клеток $\to$ контракт `BoardObservation`.
2. **Контур логико-символьного вывода (Reasoning):** конечный автомат FSM $\to$ топологические сигнатуры $\to$ генератор легальных ходов $M(B_t)$ $\to$ база знаний $\to$ целевая функция $S(m) \to$ событие `MoveEvent`.
3. **Контур последующего анализа (Analysis):** неблокирующая очередь задач $\to$ Stockfish UCI $\to$ оценка позиций и формирование аналитического отчета.

> Подробное описание архитектуры, структур данных и физических нюансов вынесено в [ROADMAP.md](ROADMAP.md).

## 4. Стек технологий

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| **Язык разработки** | Python 3.10+ | Основная реализация логики и интеграции |
| **Компьютерное зрение** | OpenCV | Геометрические преобразования, гомография, межкадровая разность |
| **Глубокое обучение** | PyTorch / Torchvision | Пакетная классификация содержимого клеток (EfficientNet-B0) |
| **Отслеживание рук** | MediaPipe Hand Landmarker | Построение маски окклюзии игровой области кистью |
| **Шахматная логика** | python-chess | Валидация легальных ходов, поддержка FEN/PGN |
| **Шахматный анализ** | Stockfish (UCI) | Асинхронный расчет оценки позиции и поиск ошибок |
| **Интерфейс** | PyQt6 / OpenCV HighGUI | Графический интерфейс оператора и видеоконтроль |

## 6. Установка и требования

### Системные требования
* ОС: Linux / macOS / Windows
* Python $\ge 3.10$
* Установленный движок [Stockfish](https://stockfishchess.org/download/) в системном пути (`PATH`)

### Быстрый старт (планируемый)

```bash
# Клонирование репозитория
git clone https://github.com/Ectrald/Chess-game-recording-system.git
cd Chess-game-recording-system

# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск системы на тестовом видеофайле
python -m src.ui.app --source data/benchmark_videos/sample_game.mp4

# Запуск полного набора модульных и интеграционных тестов
pytest tests/ -v
```
