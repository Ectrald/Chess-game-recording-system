## 1. Описание проекта

**Chess Game Recording System** — программный комплекс для автономной оцифровки, протоколирования и анализа шахматных партий в режиме реального времени по видеопотоку со стандартной физической доски (наборы Стаунтон) без использования дорогостоящих электронных сенсоров (DGT) или модифицированных фигур.

Система построена на принципах **нейросимволического искусственного интеллекта (Neuro-Symbolic AI)**: вероятностные визуальные наблюдения согласуются со строгими символьными правилами Международной шахматной федерации (FIDE) и онтологической базой знаний. Это исключает появление невозможных по правилам ходов, сбои при перекрытиях доски руками и накопление ошибок распознавания.

## 2. Ключевые возможности

* **Автоматическая локализация доски:** двухстадийный детектор границ доски (YOLO / Canny / Hough / RANSAC) и перспективная гомография с нормализацией к $640 \times 640$ пикселей.
* **Калибровка ориентации полей:** автоматическое определение стороны игрока ($a1 \leftrightarrow h8$) по цветности правого нижнего поля (правило FIDE) и начальному материальному балансу.
* **Компенсация 3D-параллакса фигур:** адаптивное вертикальное расширение области интереса клетки (Cell ROI) с коэффициентом $\alpha=1{,}25$ для устранения взаимного перекрытия высоких фигур на дальних горизонталях.
* **Изоляция динамических помех и рук:** отслеживание рук игрока (MediaPipe Hand Landmarker / Color Silhouette) и дебаунсинг затухания теней ($\Delta t_{\text{settle}} \in [0{,}5; 1{,}0]$~с).
* **Пакетная нейросетевая классификация:** параллельный инференс 64 клеток за один проход через ONNX Runtime по 13 каноническим классам (`empty`, `wP`..`bK`).
* **Логико-символьный решатель:** сопоставление визуальных изменений клеток с пространством легальных ходов $M(B_t)$ (`python-chess`) и топологическими сигнатурами (включая взятие на проходе, короткую и длинную рокировки, превращение пешки).
* **Многофакторная целевая функция $S(m)$:** взвешенное правдоподобие визуальных, временных, геометрических факторов и окклюзии с вычислением зазора уверенности $\Delta$.
* **Транзакционный журнал и аудит:** атомарная запись каждого хода в формат JSONL с криптографическим SHA-256 хеш-связыванием и защитой от внезапного обесточивания.
* **Асинхронный шахматный анализ:** фоновая оценка ходов и позиций движком Stockfish 16 UCI без блокировки основного видеоконвейера.
* **Интерактивный экран оператора (HUD):** информационная панель с наложением сетки клеток, виртуальной 2D-доской, FSM-статусами, шкалой преимущества Stockfish и диалогом разрешения неопределённости `UNCERTAIN`.

## 3. Архитектура системы

Система разделена на три взаимодействующих контура:

1. **Контур визуального восприятия (Vision & ML):** адаптер видеопотока $\to$ локализатор доски $\to$ блок проективной гомографии $\to$ детектор рук и оптического движения $\to$ экстрактор ROI $\to$ классификатор клеток $\to$ контракт `BoardObservation`.
2. **Контур логико-символьного вывода (Reasoning):** конечный автомат FSM $\to$ выявление изменившихся клеток $\Delta \mathcal{S}$ $\to$ генератор легальных ходов $M(B_t)$ $\to$ база знаний $\to$ целевая функция $S(m) \to$ шлюз решений `DecisionGate` $\to$ авторитетный `GameStateManager` $\to$ событие `MoveEvent`.
3. **Контур последующего анализа и персистентности (Persistence & Analysis):** транзакционный репозиторий `JSONLEventRepository` $\to$ модуль фотоартефактов `EvidenceWriter` $\to$ асинхронная очередь `AsyncEngineService` $\to$ Stockfish 16 UCI $\to$ PGN-экспорт и визуальный дашборд.

## 6. Установка и варианты запуска

### Системные требования
* **Операционная система:** Linux (Ubuntu 20.04+, Arch, Debian), macOS (12+), Windows 10/11 (с WSL2).
* **Интерпретатор:** Python $\ge 3.10$.
* **Шахматный движок:** [Stockfish 16+](https://stockfishchess.org/download/) в системном пути (`PATH`).
* **Видеоисточник:** веб-камера USB, RTSP-видеопоток или видеофайл (MP4, AVI, MKV).

---

### Вариант 1. Локальный запуск (Local Virtualenv)

#### 1. Клонирование репозитория и настройка окружения
```bash
git clone https://github.com/Ectrald/Chess-game-recording-system.git
cd Chess-game-recording-system

python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

#### 2. Проверка шахматного движка Stockfish
Убедитесь, что Stockfish установлен в вашей системе:
```bash
# Ubuntu / Debian
sudo apt-get install stockfish

# Arch Linux
sudo pacman -S stockfish

# macOS (Homebrew)
brew install stockfish
```

#### 3. Запуск веб-интерфейса оператора (FastAPI + WebSockets)
```bash
# Запуск веб-дашборда с подключением к первой веб-камере (доступ в браузере по адресу http://localhost:8000):
python main.py web --source 0 --host 0.0.0.0 --port 8000

# Запуск веб-дашборда для обработки видеофайла:
python main.py web --source data/benchmark_videos/game.mp4 --port 8000
```

#### 4. Запуск с десктопным графическим HUD (OpenCV HighGUI)
```bash
# Подключение к веб-камере (/dev/video0) с нативным локальным окном:
python main.py record --source 0 --display

# Обработка видеофайла с нативным окном:
python main.py record --source data/benchmark_videos/game.mp4 --out-dir data/sessions/game1 --display
```

#### 5. Пакетная обработка в headless-режиме (без дисплея)
```bash
python main.py record --source data/benchmark_videos/game.mp4 --headless --out-dir data/sessions/batch1
```

#### 6. Дополнительные утилиты CLI
```bash
# Проверка криптографической целостности SHA-256 журнала партии:
python main.py audit data/sessions/game1/events.jsonl

# Пошаговое воспроизведение записанной сессии:
python main.py replay data/sessions/game1/events.jsonl

# Запуск эталонного контрольного бенчмарка точности:
python main.py benchmark --pgn-ref data/ground_truth/test_short_game.pgn
```

#### 7. Запуск комплекса автоматизированных тестов
```bash
pytest tests/ -v
```

### Вариант 2. Запуск в Docker (Мультиплатформенная контейнеризация)

Контейнеризация обеспечивает запуск системы без необходимости ручной установки системных пакетов и зависимостей OpenCV/Stockfish.

#### 1. Сборка Docker-образа
```bash
docker build -t chess-recorder:latest .
```

#### 2. Запуск через Docker Compose (Рекомендуемый способ)
В `docker-compose.yml` настроены 3 независимых профиля:
```bash
# Профиль 1: Запуск Web UI (рекомендуется для повседневной работы, не требует X11):
docker compose up chess-recorder-web
# После запуска откройте браузер: http://localhost:8000

# Профиль 2: Headless бенчмарк (для слабых ПК, серверов и CI, потребление памяти <150 МБ):
docker compose run --rm chess-recorder

# Профиль 3: Интерактивный GUI-режим с камерой (требует локальный X-сервер):
xhost +local:root
docker compose run --rm chess-recorder-gui
```

#### 3. Прямой запуск контейнеров через Docker CLI
```bash
# Запуск Web UI с USB-камерой:
docker run --rm -p 8000:8000 --device /dev/video0:/dev/video0 \
  -v "$(pwd)/data:/app/data" \
  chess-recorder:latest web --source 0 --host 0.0.0.0 --port 8000

# Запуск эталонного бенчмарка (Headless):
docker run --rm -v "$(pwd)/data/sessions:/app/data/sessions" \
  chess-recorder:latest benchmark --pgn-ref data/ground_truth/test_short_game.pgn

# Обработка локального видеофайла в Headless-режиме:
docker run --rm -v "$(pwd)/data:/app/data" \
  chess-recorder:latest record --source data/benchmark_videos/game.mp4 --headless --out-dir data/sessions/docker_run
```

### Пользовательские интерфейсы и способы взаимодействия

В системе предусмотрено три взаимодополняющих режима работы, адаптированных под различные сценарии эксплуатации и производительность аппаратного обеспечения:

#### 1. Веб-интерфейс оператора (Web UI — `python main.py web`)
Современное кроссплатформенное одностраничное приложение (SPA), открывающееся в любом браузере (`http://localhost:8000`) на ПК, планшете или смартфоне без необходимости проброса графических библиотек:
* **Видеоканал высокого разрешения (MJPEG):** живой поток с камеры с наложением контура доски, сетки полей, маски окклюзии рук и индикатора FSM;
* **Интерактивная 2D-доска:** векторная отрисовка фигур (SVG), подсветка полей последнего сделанного хода и подсветка короля при шахе;
* **Аналитика Stockfish:** плавная шкала преимущества в сантипешках ($\pm cp$ или $M$) с индикацией лучшего рекомендуемого хода;
* **Протокол ходов:** таблица нотации FIDE SAN с автоматической прокруткой и цветными бейджами качества (`[BEST]`, `[GOOD]`, `[BLUNDER]`);
* **Панель управления оператора:** кнопки «Пауза / Продолжить», «Откат хода» (Undo), «Рекалибровка доски», «Скачать PGN»;
* **Модальное окно `UNCERTAIN`:** всплывающий диалог при спорных ходах с карточками кандидатов и кнопками подтверждения в один клик либо вводом UCI.

#### 2. Десктопный HighGUI HUD (`python main.py record --display`)
Нативное графическое окно OpenCV $1280 \times 720$ для прямого локального мониторинга с клавиатурными горячими клавишами:

| Клавиша | Действие |
| :---: | :--- |
| `Space` | Поставить видеорегистрацию на **Паузу** / Возобновить запись |
| `R` | Инициировать **принудительную рекалибровку** ориентации доски |
| `Z` | Выполнить **откат последнего хода** (операторский Undo) |
| `U` | **Автоматически принять** наиболее вероятный ход при статусе `UNCERTAIN` |
| `1` .. `5` | **Выбрать конкретного кандидата** из списка предложенных при `UNCERTAIN` |
| `P` | Экспортировать текущую позицию партии в файл **PGN** на диск |
| `Q` / `Esc` | Штатно завершить сеанс записи, сформировать манифест и выйти |

#### 3. Консольный режим (Headless CLI — `python main.py record --headless` / `benchmark` / `audit`)
Специально спроектирован для маломощных компьютеров, встраиваемых микрокомпьютеров (Raspberry Pi, mini-PC), удаленных серверов без монитора и автоматизированных CI-пайплайнов. Полностью отключает создание любых окон, веб-серверов и сокетов, обеспечивая максимальную скорость инференса и минимальное потребление оперативной памяти (<150 МБ ОЗУ).
